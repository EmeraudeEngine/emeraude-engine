- Used in: `src/Graphics/LTCTables.cpp` (the tables, verbatim), `src/Graphics/Effects/Shared/LineLightGLSL.hpp` (the

Hill and David Neubelt. ACM Transactions on Graphics (Proceedings of ACM SIGGRAPH 2016) 35(4), 2016. Project page:

- Used in: `src/PlatformSpecific/SystemLocation.windows.cpp` (a table DERIVED from `windowsZones.xml`: each Windows time
  zone and territory with the coordinates of its tz database city), generated by `tools/windows-zones/generate.py`.
  The coordinates come from the tz database (`zone.tab`, `zone1970.tab`), which is in the public domain.
- Source: https://github.com/unicode-org/cldr, `common/supplemental/windowsZones.xml`
